# 正式实验阻塞项与风险记录

更新时间：2026-08-12。以下问题不会阻止代码静态测试，但会阻止论文正式实验或限制结论有效性。

## 必须由用户/领域专家补齐

1. **论文点名的军用标准/内部规范原文仍缺失**（阻塞军事规范结论）  
   已下载并抽取 OGC CDB、CityGML、GeoTIFF 等4份公开技术标准，共998条章节/术语记录，可支持合成环境、场景要素、资源路径、CRS与DEM规则。但 GJB 6787-2009、GJB 7566-2012、《战术级战场环境建模与仿真规范》等原文仍未提供，详见 `corpus/standards/pending_restricted_sources.jsonl`。公开OGC标准不能冒充中国军用标准，因此当前只能研究“公开仿真/地理空间规范检索”，不能声称已完整测试论文列出的军用规范。

2. **正式任务集与金标准为空**（阻塞）  
   `data/tasks.jsonl` 当前 0 条。需要冻结正式任务、类别、难度、多轮关系、随机顺序和重复次数。若外部判定器需要 gold JSON，应补充 `gold_json_path` 或另行冻结判定规则版本。

3. **EnvModels 已盘点，但 UE 类路径尚未核实**（高风险）  
   已从 `E:\UE_project\LandscapeTool\Content\EnvModels` 登记4,642个文件并推导 `/Game/EnvModels/...` 候选路径。静态包头可辅助识别 Blueprint、StaticMesh、Material 和 Texture，但本阶段未启动UE，尚无 Asset Registry 的 `AssetClassPath/GeneratedClass`，也没有人工中文别名。普通纹理/材质不能直接当作插件 `actor_path`。旧库中的5条目录外临时记录已设置为不准入索引，并保留供审计。

4. **外部 JSON 正确性判定器尚未接入**（阻塞正式评分）  
   当前校验只覆盖 JSON Schema、插件字段/顺序、任务身份和资源路径证据，不覆盖论文中的空间语义、军事/业务规范满足度、拓扑等价和数值容差。用户计划采用的其他判定方法需要固定输入输出契约、版本和容差配置。

## 外部服务待验证

5. **大模型 API 未调用验证**（待验证）  
   按要求本次没有调用 API。即使本地存在凭据，也未验证 endpoint、模型名、额度、网络、限流、超时、JSON 可解析率及随机性。首次 smoke test 应使用非正式样本并单独保存结果。

6. **嵌入 API 未调用，索引未构建**（阻塞 G1–G3）  
   需在语料冻结后构建 G1/G2/G3 三套索引。不得在不同组使用不同嵌入模型或不同语料版本。

7. **公开标准的章节抽取需要抽样复核**（冻结前必须）  
   PDF签名、页数、标题与SHA-256均已校验，目录页噪声也已过滤；但章节边界来自规则抽取，正式实验前仍需抽查每份标准的高频主题章节，确认标题、页码和正文未错位。

8. **当前工程没有可用的 Git 提交标识**（可复现性风险）  
   运行器会保存实验代码快照哈希作为替代，但正式实验前仍建议把冻结版本纳入有效 Git 仓库或只读归档。

## 从 UE 插件源码发现的工程问题

9. **旧 Python 与插件坐标键大小写冲突**（明确缺陷）  
   `LCA/create_road.py` 等旧脚本验证/发送大写 `X/Y/Z`，但 `UnrealMCP-master` C++ 源码读取小写 `x/y/z`；缺失字段会落为默认数值。新 ScenePlan Schema 已强制小写，但旧在线执行链路仍需另行修复。此次按要求未改旧链路。

10. **插件没有统一删除协议**（能力缺口）  
   多轮 `delete` 暂时只能在离线完整状态中表达，无法直接映射到已检查的 Landscaping/RoadAuto/RiverAuto/BuildAuto 命令。

11. **当前阶段仅覆盖四类对象**（范围限制）  
   ScenePlan 1.0 包含 terrain、road、river、building_area。FoliageAuto、Datasmith、编辑器状态查询、Actor 生命周期管理暂未纳入，以避免扩大首轮论文实验变量。

12. **未启动 UE 做运行时契约验证**（按用户要求）  
    插件契约来自源码静态分析，未验证端口、消息边界、插件版本、蓝图资产存在性和执行副作用。论文若只报告离线 JSON 正确率，应明确这是“协议级离线评测”而非 UE 执行成功率。

## 实验设计边界

13. **当前没有重排序器**  
    四组统一采用向量余弦排序。若以后加入 reranker，必须作为新变量或对所有 RAG 组统一启用，不能只给 G3。

14. **统一切片采用字符窗口而非 tokenizer token**  
    当前固定 400 字符、重叠 80 字符，避免模型 tokenizer 依赖并保证完全可复现。论文应准确表述为“字符窗口”；若改为 token 切片，需冻结 tokenizer 和版本并重建所有索引。

15. **G3公开标准当前按条款层级切分，不是严格的300–800 token窗口**  
    当前998条记录保留标准号、章节号、父章节、页码和来源，并将超长正文切到最多约3,200字符；短条款不会为了凑长度而跨章节合并。若论文必须声称“300–800 token、100–150 token重叠”，需先冻结 tokenizer 并增加层级感知的二次窗口；否则应把论文方法改写为“条款边界优先、仅对超长条款分段”。
